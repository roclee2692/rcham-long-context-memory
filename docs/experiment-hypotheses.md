# 实验假设与证据边界 v0.1

记录日期：2026-09-14。性质：待检验的研究计划与已完成预实验的证据登记。

完整研究目标是模型内部的**局部 Attention → 多尺度向上压缩 → 同一层级向下回读 → 将必要细节送回当前计算**。外部检索可以用于隔离测试其中的组件，但组件实验不能代替神经模型内部机制的验证。整体架构见 [architecture-v0.1.md](architecture-v0.1.md)。

本文件不预设新方法会成功。支持假设、发现适用边界、得到负结果，都应记录。后续调整假设、预算、主要指标和测试范围，应通过新版本说明原因，不能在看过测试结果后悄悄修改成功标准。

## 当前证据登记

已经运行的是无训练的 NumPy 合成向量导航预实验：64 维原始记录，每 16 条取均值形成叶块摘要，每 4 个摘要继续合并。先建立索引，再产生查询；原始记录完整保留。它没有训练语义压缩器、语言模型或 Attention 模块。

下表使用 4,096 条记录，每种条件包含 9 段历史、180 个问题。两种方法最终都读回 64 条原始记录；数值是目标证据召回率，不是自然语言回答正确率。

| 数据条件 | 扫描全部叶块摘要 `flat_4` | 分层导航 `tree_beam_4` |
|---|---:|---:|
| 随机向量 | 37.22% | 17.78% |
| 相同主题聚集 | 72.78% | 72.78% |
| 同一批主题记录打乱 | 12.22% | 8.89% |

两种方法分别给 256 和 52 个摘要打分，但本次 Python 树实现没有获得更短的查询耗时。主题聚集与打散复用相同记录和问题，只改变排列。已知主题的有利分组是生成条件，不代表模型已经学会语义分组。9 段历史只是小型先导样本，不能把同一历史中的所有问题都当成独立重复。

这轮结果表明：在这些合成条件下，均值压缩和上层剪枝会丢失导航信号，减少比较次数也不自动产生实际加速。它尚未验证语义压缩、可训练导航、状态重建或替代全局 Attention 的整体收益。

## H1：在有限存储下，压缩表示能直接保留任务所需信息

**假设。**未来问题未知时建立的可训练压缩表示，在相同表示字节数下，相比简单均值压缩和参数预算相近的压缩基线，能够提高下游任务正确率，或在相同正确率下减少表示存储。

**实验。**固定局部编码器与读取器接口，比较未压缩表示、均值压缩、可训练压缩；压缩方法一律禁止回读原文。扫描压缩比和总表示预算，覆盖一次性事实、否定或条件、跨段关联、状态更新与整体概括。未压缩表示是容量参照，不能被称为相同存储预算的竞争方法。

**主要指标。**每类任务的答案精确匹配率、实际表示字节数、质量—存储曲线。区分常见内容与只出现一次的关键事实。

**不支持假设的结果。**可训练压缩在预算匹配后没有稳定优势，或者优势只存在于训练模板。若允许原文回读后才改善，也不算 H1 得到支持。有限有损表示不能被要求无损保存任意数量的独立随机事实。

**状态：未验证。**当前预实验没有“仅用压缩表示回答”的读取器。

## H2：为导航保留独立表示，有助于找回容易被概要掩盖的细节

**假设。**在相同总索引字节数和原始读取预算下，将“内容概要”与“导航表示”分别学习，比每个节点只使用一种概要表示，更容易找回稀有事实、否定条件和完整的多条证据。

**实验。**共用原文档案、层级组织、读取器和搜索策略，只替换节点表示。比较单概要表示与概要加导航表示；允许单表示对照调整维度或节点配置以匹配总索引预算。先只改节点表示，再做其他改动，避免无法归因。

**主要指标。**必要证据召回率、全部必要证据找齐的问题比例、逐层目标分支存活率、答案正确率。额外给读取器输入标准证据，区分“找不到”和“找到后不会用”。

**不支持假设的结果。**优势在匹配总存储后消失，或者只对实体字面匹配有效，遇到改写、否定和多条证据时不再成立。不能用增加表示数量但不计新增空间的方法宣称改进。

**状态：未验证；已有失效诊断。**均值摘要在混杂条件下遗漏证据，说明这个问题值得测；它不能证明独立导航表示一定能解决。

## H3：有限候选的层级导航能改善质量与检索成本的取舍

**假设。**在匹配索引字节数、原始读取预算和目标质量时，有限候选的多层导航比扫描全部叶块摘要需要更少的检索工作，并能在足够长的历史上转化为端到端收益。

**实验。**比较平坦叶块选择、单候选树搜索、每层全局有限候选搜索；分别报告纯导航消融和各自实际部署空间。固定最终原始读取上限，并扫描候选数量、块大小与历史长度。完整原始扫描只作非预算匹配的诊断参照。

主题有序与打乱使用同一批数据和问题，检查对排列的依赖；补充跨块证据、窗口边界、稀有细节与不同噪声条件。任何回退、横向连接或重新搜索都必须计入成本。

**主要指标。**质量—成本曲线、摘要打分数、展开节点数、原始读取量、真实耗时、索引字节数；拆开建树、路由、读回和数据搬运。多次查询摊销时明确查询次数。

**不支持假设的结果。**匹配质量后需要大量回溯，成本接近平坦扫描；或虽然比较次数减少，实际耗时与总空间没有改善。只在已知主题排好序时成立，应记录为适用条件限制。

**状态：部分诊断，整体未验证。**预实验显示 4,096 条记录下摘要打分从 256 次降到 52 次，但随机和打散条件的召回下降，且树原型没有更快。不能据此声称质量—成本曲线已经改善。

## H4：因果写入与快照／变化记录能可靠恢复指定历史状态

**假设。**在只读取已出现历史的条件下，增量建立的层级记忆结合状态快照和变化记录，能够在有限读取预算内恢复指定时刻的状态，并减少旧版本、漏条件和错顺序造成的回答错误。

**实验。**用程序生成带明确生效时间和证据 ID 的状态历史，覆盖修改、撤回、条件生效和跨实体关联。比较完整顺序历史参照、只保留最新状态、普通分块检索与快照加变化记录。所有方法使用相同问题和读取器；匹配可比的总存储或报告完整取舍曲线。

**主要指标。**指定时刻的状态精确匹配率、必要变化证据完整率、旧版本错误率、重放步数、存储与读取成本。信息缺失时，推测不能记作已恢复的事实。

**不支持假设的结果。**得到的正确率依赖未来摘要、问题参与写入或人工提供目标事件；或保存和重放成本抵消预期收益。快照和变化只能恢复确实保存的信息，有损摘要不能被当作可逆压缩。

**状态：未验证。**当前预实验没有时间、状态变化或快照重建。

## H5：接入模型内部后，整体架构能改善长上下文质量与成本

**假设。**将局部 Attention、增量多尺度压缩、层级导航和有限回读共同接入自回归模型，在合理匹配模型与训练预算后，能在部分长上下文任务上改善质量—时间或质量—内存取舍，同时明确短上下文能力与长度外推的变化。

**实验。**在小型模型上比较全局 Attention、仅局部 Attention、局部 Attention 加平坦块选择，以及完整层级方案。先逐项加入压缩、导航、回读，再测试联合训练。报告模型参数、训练数据、训练 FLOPs 和墙钟投入；无法同时匹配的项目明确列出。

预测第 t 个 token 时，所有可见摘要的来源范围必须止于 t 之前。重新编码原文块不等于原模型当时的原始 KV；两种记忆形式分别验证，并计入各自的存储和计算。

**主要指标。**任务正确率、语言模型预测损失、输入处理时间、逐 token 生成时间、峰值热内存、冷热总存储、长序列扩展曲线与训练成本。速度比较使用优化过的 Attention 对照，不用慢速 Python 实现制造优势。

**不支持假设的结果。**组件收益不能迁移到模型内部；明显损伤短上下文能力；或导航、重编码、数据搬运及维护成本抵消局部计算的节省。固定局部窗口的 O(nw) 只描述局部注意力项；树深度为 O(log n) 也不保证全部 token 的完整计算为 O(n)。

**状态：未验证。**没有完成神经模型改造、训练、KV 缓存或设备搬运实验。

## 所有正式实验共用的协议

1. **写入时不知道未来问题。**压缩器和索引建立过程只看历史；问题可以用于读取及训练损失，但不能成为该次写入的输入。自回归训练检查每个节点的来源范围，避免未来信息泄漏。
2. **按整段历史划分数据。**同一历史的不同问题不拆入训练、验证和测试集合；保留未见实体、随机值、表达模板与长度条件。先在验证集选参数，再冻结测试集运行。
3. **存储按字节核算。**包含所有层的表示、精度、索引、指针和元数据；另报原文或原始 KV 档案。热记忆缩小不能称作冷热总空间压缩。
4. **读取与搜索分别计量。**既记录最终读入多少原文，也记录为找到它打分和展开了多少候选。候选宽度是每层总上限，不能每个父节点各自无界扩张。
5. **跨任务、长度和随机种子重复。**正式训练的关键配置至少使用 3 个独立种子。按整段历史做配对统计与置信区间；同一历史的问题相关性必须保留。先导样本量只用于估计后续规模。
6. **报告失败而非只报总平均。**按任务、长度、证据位置和排列分组；保留原始问题、必要证据、逐层剪枝轨迹与结果。正式主要指标和可接受差距在最终测试之前固定。

## 分阶段产出与可作出的结论

| 阶段 | 可交付产出 | 允许的结论范围 |
|---|---|---|
| 第零轮：无训练导航诊断，已运行 | 可复现脚本、原始记录、汇总、失败轨迹 | 合成向量条件下的均值索引和遍历表现 |
| 第一轮：小型组件训练，待执行 | H1–H3 的预算匹配对照与消融 | 指定任务上压缩、导航、读取的组件能力 |
| 状态恢复分支，待执行 | H4 的时序证据和状态评测 | 指定保存规则下的历史状态恢复能力 |

第一篇研究可以只验证一个组件，或系统地解释一种重要失效模式；不必宣称已经实现完整架构。后续训练、公开基准复用与实施建议见 [第一阶段实验方案](../outputs/research_plan.md)。
