# 思想与版本记录

## 2026-09-14：v0.1 首次仓库留档

来源：本次用户与 AI 的架构讨论、用户明确纠正后的核心陈述，以及当日运行的预实验。原始架构方向由用户提出；AI 辅助整理优化建议、实现预实验并建立档案。

### 原始思想的重点

用户明确的目标是降低全局 Self-Attention 的 O(n²) 两两交互成本，同时保留长期信息可访问性。应始终保留以下主干：

> 局部理解 → 分层压缩 → 长期保存 → 主动回忆 → 必要时重建过去。

具体包括 CNN 式多尺度层级、窗口内 Attention、逐步降低活跃精度、动态重要度、上下层索引、时间/实体/因果等回忆线索、快照与增量，以及回读内容重新进入当前计算。

用户特别指出：只讨论外部 Agent 数据库或局部历史重建，会漏掉最重要的模型计算架构。后续版本应继续把“理解时向上压缩、回忆时沿同一层级向下展开”作为架构中心。

### 同日讨论形成的优化候选

- 分开用于内容理解的表示与用于导航的表示，保留低频关键细节的查找线索。
- 有限候选束、逐步展开和按需读取精度，记录上层剪枝造成的遗漏。
- 树形主干加少量跨段逻辑连接；窗口边界策略需验证。
- 先采用规整窗口和动态表示预算，再研究完全动态边界。
- 压缩与未来使用共同训练，写入时不得偷看未来问题。
- 回读细节可以修正当前理解；持久修改需要来源和版本。
- 整体复杂度包含导航、重建和搬运，近 O(n) 是目标，不能作为未经验证的结论。

以上为待检验建议，未将其声明为本项目独有创新。

### 已运行的初步结果

已完成合成向量上的均值摘要导航探针，包含 3 个长度、3 个情景、7 种扫描/树搜索设置。原始数据完全保留，未训练神经网络。

4,096 条记录、相同读回 64 条预算下，主题聚集时平坦和树形召回均为 72.78%；将同一批记录打散后分别为 12.22% 和 8.89%。随机向量条件下分别为 37.22% 和 17.78%。

这支持继续研究分组、压缩表示与导航遗漏的关系；不能证明语义压缩有效、完整架构成熟或模型性能提升。
