## 为什么选择冻结

1. **不永久放弃：**[源码及原始记录审计](reports/research_closeout.md)发现，Phase 1R 没有有效比较真实模型的 task utility 和忠实的 RMM signal。词面 scorer、没有产生独立任务的 seeds、证据 ID 代替实际回答等问题，使结果不足以否定目标命题。
2. **不立即重做：**同一审计也没有提供可信的正证据。下一次验证必须先修正测量和比较契约，不能只把词面 scorer 换成 LLM 就认为实验有效。实验可信度不足是此前实现与报告的问题，不是用户的想法被推翻。
3. **保留重启选择：**已有文献、源码和负结果仍有价值。保存它们的成本低于直接承诺新一轮研究；但这种判断不等于已经计算了项目预期收益或证明新实验太贵。本次没有测算真实模型实验的运行时间、显存或费用。

“未找到完整同构工作”只描述已有检索的范围，不能推出明确的文献空白；“可能影响 Attention 的组织方式”也不是已经测得的收益。组件重叠不排除组合创新，但组合价值仍需可归因的证据。

## 重启前需满足的三个条件

这些是重新评估是否值得实验的条件，不是待自动执行的任务。不要求先拿到正结果才能重启，也不要求更换核心假设来规避旧结果。

### 1. 测量契约通过独立检查

提前写清并由另一位具备机器学习实验经验的审阅者检查：

- 指定一个重要且可测的失败情形，结合最接近的两三项工作解释待比较的差别。不能仅凭“完整组合未被找到”立项；也不要求预先证明新颖性或正结果。
- frozen LLM 必须真实计算 gold-answer token 的条件 log probability；逐块移除对上下文和位置的处理必须明示。该分数是针对 q1 的模型贡献测量，不是自动等于未来价值。
- Attention 来自模型，RMM 的定义、观察窗口、更新时点及任何适配差异可追踪。若无法实现可比较的 RMM，对它的比较主张必须收缩，不能用手工 proxy 顶替。
- 未来问题不进入 q1 前的写入或 q1 utility；q2/q3 使用每种策略实际保留的上下文让模型答题。证据可用率与答题准确率分开。
- 相同容量、候选、admission 和信息可见时点；测试问题不是 q1 改写，独立样本不能只改变无作用 nonce。真实模型也不能弥补不独立的数据或偏置 admission。
- 先限定验证对象：文本块保留的真实模型实验只能检验信号是否有用，不能直接证明内部 KV 生命周期、Attention 架构或加速有效。

导师即使主要做知识图谱/RAG，也可以检查数据独立性、因果时间线和评分有效性；若无法审查 RMM/KV 细节，需要相应技术审阅补充。本次不联系任何人。

### 2. 有可执行且封顶的资源方案

明确可用模型、能否取得所需 log probabilities 和 attention、运行设备、实现工时和运行预算。优先复用可审计的现成实现，减少重新造实验工具的负担。

先给出小规模 smoke test 的最大样本数、调用次数、时间和费用上限，由用户另行批准。不能仅因有了 GPU 就重启，也不能未经测算承诺“几分钟就能完成”。

### 3. 结果揭晓前写定决策规则

预先区分方法/测量无效、信号无分歧、有效对照下无收益、有效对照下有收益。锁定主要指标、比较对象、数据划分和最小有意义差异；有限样本的不确定性必须保留。

无论结果如何，先报告并停止，不能自动加 hierarchy、decay、future-reuse predictor 或硬件 tier。用户明确同意重启后才可运行；即使信号有收益，也要另行判断其测量成本和部署可用性，不能直接进入完整 RCHAM。
