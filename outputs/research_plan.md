# 局部注意力、层级压缩与可回溯记忆：第一阶段实验方案

日期：2026-09-14。性质：研究计划；除同目录预实验结果外，下文均为待执行方案，不是已经验证的结论。

## 研究目标与结论边界

完整目标保持不变：局部窗口 Attention 处理输入，向上形成多尺度表示；同一层级保留细节入口；需要历史时向下展开，把必要信息送回模型计算。

将“有效”分为三个可以分别检验的问题：

1. **压缩表示有用**：只读压缩表示，不读原文，模型仍能完成哪些任务？相同存储预算下，哪种压缩更好？
2. **压缩索引可导航**：原文另存时，模型能否找到回答所需的全部证据？找到这些证据花了多少计算与数据读取？
3. **整模收益成立**：把模块接入模型内部之后，训练、输入处理、逐 token 生成的质量、时间、峰值内存是否优于合适的对照？

第 2 项成功不能代替第 1 项，也不能证明第 3 项。原文仍在档案中时，必须把冷存储计入总空间；不能把热记忆缩小称为总存储压缩。

## 本次已开始的第零轮：机械导航预实验

位置：`outputs/compression_probe/`。使用本机 Python 和 NumPy，原始记录是有确定 ID 的合成向量，不是自然语言；没有训练语言模型，没有运行真实语义摘要。它只检查均值压缩、分组、树形剪枝与读取预算的关系。

参照方法包括全扫描原始向量、全扫描叶块摘要，以及在同一索引上进行的不同宽度树搜索。全扫描原始向量是使用更多原始信息的诊断参照，不是预算匹配的竞争方法。最终定位使用确定性向量匹配，不称为 LLM 回答正确率。

主题有序和主题打散应使用同一批记录、同一批查询，仅改变分组；随机向量是另一个压力情景。索引构建不接收未来问题。报告每个查询、每段历史、每种长度的数据，保留错误轨迹。结果仅能说明这些合成条件下的导航表现。

## 第一轮：训练小型压缩与召回组件

### 数据

先用可追溯合成历史，因为可以知道问题所需的精确证据集合。至少覆盖：

| 类型 | 示例 | 不能遗漏的细节 |
|---|---|---|
| 一次性事实 | 某设备的随机编号只出现一次 | 随机值、准确来源 |
| 否定或条件 | 通常允许启用，但检修期间禁止 | 否定词、条件作用范围 |
| 跨段连接 | A 负责 B，B 属于 C | 两条证据都要找回 |
| 状态更新 | 阀门先打开，后来关闭，再问某时刻状态 | 生效时间、更新顺序 |
| 整体概括 | 多段事件共同说明总体变化 | 分散证据的覆盖 |

初始训练长度可选 2K/4K；评估 2K/4K/8K/16K，再按实测内存扩大。每类先生成 200 个验证问题、至少 500 个最终测试问题；最终样本量按先导实验方差调整。训练数据按训练预算在线生成或固定归档。长历史中相关证据位置均匀分布，并保留位置标签。

借用已有任务生成方式，避免把整个数据基准从零重写：

- RULER：多目标查找、变量追踪、聚合等；固定仓库 commit、任务版本和配置，不混合旧版脚本与新版成绩。https://github.com/NVIDIA/RULER
- BABILong：长干扰文本中的事实组合与推理。https://github.com/booydar/babilong

训练、验证、测试按整段历史划分，不把同一历史的不同问题拆进不同集合。随机事实值、实体和部分表达模板留作测试；用措辞变化与新增任务检查是否只学了生成模板。写入器只能看到历史，未来问题只供读取器和训练损失使用。

### 模块

先实现小型可训练模块，而不是预训练一个完整大模型：局部编码器将每块压缩成有限数量的向量，聚合器合并相邻节点，导航器选择下一层节点，读取器从压缩表示或被选中的细节产生预测。

可从百万至千万参数量级开始。具体参数上限、batch 和长度要用 MLX 内存试跑确定；不把参数量当作性能承诺。模型使用浮点向量表示时，明确维度和精度，不能用“一个向量”与“一段文本”直接比较存储大小。

### 对照组与两个独立试验

**试验 A：压缩后直接使用。** 使用相同编码器与读取器，比较原始表示、均值压缩、可训练压缩。全部压缩方法禁止回读原文，扫描压缩比和存储预算，测任务答案正确率；至少保留一个参数预算相近的压缩基线。完全随机的独立事实是容量压力测试，不要求有限有损表示无损恢复所有事实。

**试验 B：压缩后导航回读。** 使用同一原文档案和同一读取器，比较全扫描块摘要、单表示层级树、候选束搜索，以及后续多个导航表示的树。首次只替换导航，随后再替换压缩器，避免同时改变所有模块而无法解释收益。

多导航表示增加了空间，须绘制多个总索引字节预算下的曲线；同预算也要比较单表示方法可否使用更多节点或更大维度。不能仅在节点数相同时宣称多表示更优。

### 固定与记录的预算

- 总索引字节：所有层、所有表示、位置和指针元数据。
- 原文档案或原始 KV 字节：单独报告；还要报告热端加冷端的总量。
- 每题读回原文 token 数：固定上限并报告实际值。
- 路由候选打分数、展开节点数、回退次数：搜索成本不得藏在最终输入预算外。
- 建树成本、训练成本、输入处理时间、生成时间、数据搬运时间：分开计量；多次查询摊销需要明确查询数量。

候选束宽度是每层全局保留数，不是每个父节点都保留若干孩子后无界扩张。任何全扫描回退都计费。树的深度是对数，不意味着高召回搜索必然只付对数成本。

### 指标与错误分析

1. 答案正确率：合成事实用标准化后的精确匹配，不比较两个模型内部打分的数值大小。
2. 证据召回率：找回的必要证据比例；另外报告“全部必要证据都找齐”的问题比例。
3. 正确证据给定时的读取正确率：单独将标准证据送给读取器，隔离模型不会推理与导航找不到的错误。
4. 状态题旧版本错误率；错误条件、否定词和时间范围分别标记。
5. 压缩程度、索引大小、原文大小、热端峰值内存、端到端耗时。
6. 逐层目标分支存活率：确定重要信息在哪层被剪掉。

关键配置至少三个独立训练种子。按整段历史做配对 bootstrap，不把同一历史中的大量相似问题当作完全独立样本。先在验证集选择参数，再一次性使用冻结测试集。报告按任务和长度分组的结果，避免平均分掩盖某类崩溃。

### 怎样判断值得继续

提前设一个工程目标，例如“相对最强预算匹配对照，答案差距不超过 2 个百分点，同时明显减少读取量或总成本”。这是可调整的研究目标，不是预告结果；应在正式测试之前根据使用场景确定。

最有说服力的证据是质量—成本曲线整体改善，并且收益能跨长度、跨任务和跨随机种子保留。若准确率下降但成本下降，结果是可量化的取舍，也可能值得研究。若只在主题排列整齐的数据上有效，需要明确适用条件，并检验混杂、稀有事实和跨段关系。

## 第二轮：接入小型语言模型

组件表现稳定后，再把局部注意力、层级写入、导航和读回接进自回归模型。必须满足因果性：预测某位置时不能读到含未来 token 的摘要；增量写入与离线索引是不同条件。

适当的参照包括全局 Attention、仅局部 Attention、局部 Attention 加平坦块选择。比较尽量匹配模型规模、训练数据和训练投入，并分别报告短上下文能力和长度外推能力。不同架构无法严格同时匹配参数、训练 FLOPs 和墙钟时间时，要清楚说明比较口径。

把重新编码的文本块当作记忆输入，需要设计位置与边界信息；它一般不等于原模型当时的原始 KV。若保留原 KV，必须计入其完整存储与搬运成本。

MLX 原型可以验证算法与训练可行性；若比较 GPU 加速，还需与优化过的 Attention 实现在合适设备上比较，不能用慢速 Python 全注意力证明新算法实际更快。

HiLS 可作为研究训练目标、块选择与现成评测入口的参考；本次只核验过公开入口，未复现其论文结果。https://github.com/Tencent-Hunyuan/HiLS-Attention

## 学生、导师与第一篇论文

本机已读取到 Apple M5、16 GiB 统一内存；Python 中 NumPy 2.4.2、MLX 0.32.1 可用，MLX GPU 简单运算通过。适合数据构造、导航实验、小型模块训练和部分小模型实验；不能据此断言能低成本复现大模型继续预训练规模。

在有 Python 基础、每周投入约 10–15 小时的前提下，粗略规划：可复现实验框架 1–2 周；包含训练、排错的组件实验 4–8 周；补齐强基线、真实数据、多种子与写作通常需要 2–4 个月或更久。学习神经网络训练、出现负结果或调整方向都会延长时间。这些是排期估计，不是完成或录用保证。

建议现在联系导师，同时自己开始实验。导师的知识图谱、RAG 和水利领域经验可以支持检索对照、证据标注、规则条件、时序更新和论文论证；模型内部注意力训练部分需要时再请教相关合作者。

可以先在一般任务上验证机制，再增加水利领域的版本规范、设备状态和条件约束任务。不要只为了贴合导师方向就把整个研究目标改成外部 RAG，也不要把领域检索的结果写成已经改进 Transformer。

可向导师这样介绍：

> 老师，我想做局部注意力与层级压缩记忆的研究。第一阶段先检验：在未来问题未知的情况下，压缩表示能保留多少有用信息，以及分层检索能否在相同预算下找回完整证据。我会先做合成数据和公开基准的对照，再考虑水利领域的规则条件、状态变化和知识关联。我准备了实验方案与初步代码，想请您帮我判断问题是否值得收窄成一个论文选题。

第一篇可以只贡献一个经过验证的组件或系统性失效分析，并公开代码与数据。完整架构作为展望是可以的；只画整套蓝图、期待其他人补齐实验，通常不足以支撑一篇有说服力的实证方法论文。是否达到投稿要求，要看相关工作差异、证据完整度及导师和同行的反馈。
